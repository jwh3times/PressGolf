# Workspace

## Private companion

none

## Safe-to-remove paths

- `coverage/` — `npm run test:coverage` output (`coverage/lcov.info` feeds the patch-coverage script)
- `dist/`, `web-build/` — `npx expo export` output (`npm run test:web` exports to `dist/`)
- `test-results/`, `playwright-report/` — Playwright failure output, never the baselines under
  `tests/web/__snapshots__/`
- `*.tsbuildinfo`, `.metro-health-check*`, `npm-debug.*`, `__pycache__/`
- `site/.wrangler/` — local state from `npx wrangler dev`; the site has no bindings
- `ios/`, `android/` — generated by a local `npx expo run:*` or `expo prebuild`; only once the user
  is done with that development build

## Never-remove paths

- `.env`, `.env.*` (all but the tracked `.env.op`) — resolved values; `.env.op` holds only
  1Password references
- `supabase/.temp/` — the `npx supabase link` state that `db:push`, `db:status` and
  `db:lint --linked` use; recreating it needs the maintainer's login
- `supabase/.branches/`, `supabase/.env.keys`, `supabase/.env.local`
- `.expo/` — Expo's local device and dev-server state, not debris
- `*.jks`, `*.p8`, `*.p12`, `*.key`, `*.pem`, `*.mobileprovision` — signing material, not
  regenerable
- `node_modules/` — every check runs from it
- `.claude/settings.local.json`
- never `git clean -x`

## Dev stack

- **Show:** `npx supabase status` (the local stack, `project_id = "PressGolf"`; containers
  `supabase_*_PressGolf` in `docker ps`); `pgrep -af 'expo start|wrangler dev'` for a Metro dev
  server or the site's local Worker; running emulators (`adb devices`).
- **Stop:** `npx supabase stop` — keeps the local data. Stop Metro or `wrangler dev` from the
  terminal that started it.
- **Never run:** `npx supabase stop --no-backup` or `docker volume rm`/`prune` on the
  `supabase_*_PressGolf` volumes — they delete the local database; `npx supabase db reset`; and
  `npm run db:push` or `npx supabase db push` — they act on the linked production project, which
  only CI's `migrate` job changes.
